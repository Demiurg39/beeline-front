# Tariffly — Frontend

**Tariffly** — веб-интерфейс для анализа расходов на мобильную связь и подбора оптимального тарифа. Проект разработан в рамках INAI Hackathon 2026 (ТЗ № 2 — «Калькулятор тарифа»).

Frontend реализован на **Python и Streamlit**.

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/Demiurg39/laughing-beeline-front.git
cd laughing-beeline-front
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация:

**Windows:**
```bash
.venv\Scripts\activate
```

**macOS / Linux:**
```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск frontend

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу:

**http://localhost:8501**

## 📱 Основные страницы

- **Загрузка** — загрузка детализации мобильной связи для анализа.
- **Результаты** — статистика расходов, графики потребления и рекомендация тарифа.
- **Тарифы** — каталог мобильных тарифов и дополнительных пакетов.
- **О сервисе** — информация о Tariffly и принципах его работы.

## 🎨 Интерфейс

- Минималистичный дизайн и единая цветовая палитра.
- Переиспользуемые UI-компоненты.
- Интерактивные графики и карточки.
- Модальные окна с подробной информацией о тарифах.
- Отдельные HTML-шаблоны и CSS-стили.

## 🛠 Технологии

- **Python** — основная логика приложения.
- **Streamlit** — frontend-фреймворк.
- **Plotly** — визуализация данных.
- **HTML / CSS** — оформление интерфейса.
- **JSON** — данные тарифов и дополнительных пакетов.
- **Requests** — взаимодействие с API.
